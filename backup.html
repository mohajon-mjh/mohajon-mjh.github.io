ℹ️ এই system কেন আলাদা:
এই backup.html file admin.html থেকে সম্পূর্ণ আলাদা। যদি admin.html সম্পূর্ণ ডিলিট বা নষ্ট হয়ে যায়, এই file থেকে:
  • Firebase data backup নিতে পারবেন
  • Firebase data restore করতে পারবেন
  • admin.html এর code আলাদা করে GitHub থেকে restore করতে পারবেন
